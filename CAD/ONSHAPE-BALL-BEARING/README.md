# Onshape Ball Bearing Project

This folder contains the CAD model for a custom ball bearing created in Onshape. I followed a set
of instructions delivered online by Queen Mary Formula Student, as images.

## Objective
-  Design a ball bearing which the balls orbit around the center together in unison.
-  Design the individual components (Inner race, outer race and ball)
-  Apply and sketch dimensions correctly according to schematic
-  Build a 3D assembly using revolute and tangent mates to simulate realistic motion
-  Clone multiple balls by first designing the model ball to replicate


## Features
- Inner Race
- Outer Race
- Revolved Ball Bearings
- Fully assembled with Revolute and Tangent mates

## Conclusion
I found it quite difficult at first as I am in early stages of CAD, but ultimately pushed through 
and was able to create a full simulation of balls revolving around a ball bearing, successfully
going through all steps and designing this system with realistic physics.
